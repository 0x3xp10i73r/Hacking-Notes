# Dynamic Analysis

Dynamic analysis runs the application on a dedicated authorized device or emulator and observes behavior in real time.

## Workflow

1. Capture baseline behavior, package state, and device configuration.
2. Observe filesystem writes, logs, network traffic, IPC, and authentication transitions.
3. Repeat actions with controlled inputs.
4. Preserve logs, screenshots, requests, and hashes as evidence.

Use disposable test accounts and avoid destructive actions unless the test plan explicitly allows them.
