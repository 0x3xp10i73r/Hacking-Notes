# Tools Reference

| Tool | Purpose |
| --- | --- |
| ADB | Interact with Android devices and emulators. |
| JADX | Decompile APK and DEX into readable Java-like code. |
| APKTool | Decode and rebuild resources and Smali. |
| Dex2Jar | Convert APK or DEX content into JAR files. |
| Frida | Instrument methods and native functions at runtime. |
| Objection | Frida-based mobile exploration and common assessment tasks. |
| Fridump | Dump application memory using Frida. |
| MobSF | Automated mobile security analysis framework. |
| Burp Suite | HTTP and HTTPS interception proxy. |
| Reflutter | Patch Flutter applications for controlled traffic testing. |
| Ghidra | Review native libraries and reverse engineering targets. |
| apksigner | Verify or sign APK packages during authorized testing. |
